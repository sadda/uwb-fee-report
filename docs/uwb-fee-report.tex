\begin{frame}{Instalace + Návrhy vylepšení}
Existují dvě možnosti instalace šablony:
\begin{itemize}
\item Stáhnout template na \href{https://github.com/sadda/uwb-fee-report}{Github} stránkách.
\item Otevřít si projekt v \href{https://www.overleaf.com/read/nhmrwnfykqpf\#940003}{Overleafu} a projekt zkopírovat (Menu $\rightarrow$ Create a copy).
\end{itemize}
V obou případech se edituje soubor \texttt{main.tex}.

\vspace{5mm}

Pro dotazy použijte diskuzní fórum na výše zmíněném Github úložišti. Pro reportování chyb nebo zlepšení funkčnosti šablony založte issue nebo pull request tamtéž.
\end{frame}



\begin{frame}{Použití šablony}
Šablona je dokumentována přímo v \texttt{main.tex} souboru. V preambuli je nutné specifikovat \texttt{lang=cz} nebo \texttt{lang=en}, což změní jména obrázků, tabulek, literatury a dalších do správného jazyka.

\vspace{5mm}

Parametry \texttt{title}, \texttt{author}, \texttt{releasedate}, \texttt{department}, \texttt{reporttype}, \texttt{leader}, \texttt{reportdedication}, \texttt{customer}, \texttt{support} jsou povinné. Parametry \texttt{reportnumber}, \texttt{classification}, \texttt{confidential} jsou volitelné a mohou se smazat.
\end{frame}
